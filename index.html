کتابخانه برنامه‌ها و آموزش‌ها

راهنمای افزودن برنامه، تصویر و متن

افزودن تصویر آموزشی

۱. وارد مخزن GitHub شوید و روی Add file و سپس Upload files بزنید. ۲. تصویر JPG، JPEG، PNG یا WEBP را انتخاب کنید. ۳. تصویر را در صفحه اصلی مخزن، کنار index.html، بارگذاری کنید و Commit changes را بزنید. تصویر جدید پس از تازه‌کردن صفحه، خودش به فهرست آموزش‌های تصویری اضافه می‌شود. عنوان کارت از نام فایل گرفته می‌شود؛ بهتر است نام گویایی مانند «تشخیص-کالای-جدید.jpg» انتخاب کنید.

افزودن راهنمای متنی

۱. متن را در Notepad بنویسید. ۲. هنگام ذخیره، نامی مانند «راهنمای-انبار.txt» انتخاب کنید و Encoding را روی UTF-8 قرار دهید. ۳. فایل TXT را در صفحه اصلی همان مخزن بارگذاری و Commit changes کنید. راهنما به‌طور خودکار در بخش راهنماهای متنی نمایش داده می‌شود. عنوان کارت از نام فایل گرفته می‌شود و متن با کلیک روی «مطالعه راهنما» باز می‌شود.

افزودن صدای فارسی به راهنمای متنی

فایل صوتی MP3 را دقیقاً با همان نام فایل متنی ذخیره کنید. برای نمونه، کنار «راهنمای-انبار.txt» فایلی به نام «راهنمای-انبار.mp3» بارگذاری کنید. پخش‌کننده صدا خودکار به همان راهنما اضافه می‌شود.

افزودن برنامه

فایل برنامه را با پسوند HTML، ZIP، EXE، MSI، RAR، 7Z، BAT یا CMD در صفحه اصلی مخزن بارگذاری کنید. فایل PDF نیز به‌صورت کارت دانلود نمایش داده می‌شود. این فایل به‌طور خودکار زیر «برنامه‌ها» نمایش داده می‌شود. برای برنامه تسویه، فایل موجود «tasvieh.html» را حذف نکنید مگر آنکه نسخه جدید جایگزین آن را آماده کرده باشید.

کجا فایل را بارگذاری کنم؟

همه فایل‌ها باید فعلاً در صفحه اصلی مخزن باشند؛ یعنی کنار فایل index.html، نه داخل پوشه. بعد از Commit changes، صفحه سایت را تازه کنید. ممکن است نمایش تغییرات چند دقیقه زمان ببرد.

صفحه به‌صورت خودکار فهرست فایل‌های مخزن عمومی GitHub را بررسی می‌کند. برای این کار لازم نیست هر بار کد index.html را ویرایش کنید.
